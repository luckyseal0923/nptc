## 登入與帳號

- 後臺：Email＋密碼登入。新申請者須確認信箱並經系統管理者啟用，未啟用與停用帳號不能讀寫課程。
- 學員：老師先建立姓名、Email、手機名冊；學員以三項資料首次啟用，由 student-activate 核對名冊並建立 Auth 帳號，接著補齊個人資料與設定密碼。之後使用 Email＋密碼登入。
- 首次啟用沿用免寄驗證信的名冊核對流程；不能把 Auth 內部的 email_confirmed_at 解讀成曾實際收過驗證信。後臺申請、忘記密碼及 Email 變更需要可用 SMTP。
- 同一 Email 的學員帳號只建立一次；參加其他梯次直接登入。已有帳號但未完成啟用者，登入後接續核對名冊與填寫資料；舊有未確認信箱帳號可由登入頁重新寄送確認信。
- 名冊以紅叉、橘色時鐘、綠勾區分「尚未建立帳號」「帳號已建立，啟用未完成」「已啟用」，滑鼠停留或鍵盤聚焦時顯示狀態與個人資料。
- 已建立帳號的 Email 不能由管理員直接改名冊。學員在專區申請變更，完成 Auth 的信箱確認後，系統按同一個 user_id 同步目前及封存名冊；成績不搬動。若新 Email 與同梯次既有名冊衝突，同步會整筆回復，原紀錄仍保留，需由系統管理者核對。
- .env.local 僅放前端可公開的 publishable／anon key；service-role key 只能放 Edge Function 的伺服器環境。

## Edge Function、SMTP 與部署順序

1. 完成上述 SQL 升級。
2. 部署 supabase/functions/student-activate/index.ts，伺服器設定 SUPABASE_URL 與 SUPABASE_SERVICE_ROLE_KEY。若自架 Kong API key 與資料庫 JWT 分開設定，JWT_SECRET 必須與 Auth／PostgREST 的共享設定一致；機密僅放伺服器。CLI 使用 supabase/config.toml 的 functions.student-activate.verify_jwt=false，因為首次啟用者尚未登入；僅此函式允許匿名進入，內部仍以 service-only RPC 核對名冊、拒絕既有帳號並限制嘗試次數。自架環境須另外確認 functions gateway／runtime 有套用相同設定，單純放入 config.toml 不會自動更新 Zeabur。
3. 確認 Auth 的 Site URL 為 https://nptc-wfh.zeabur.app，Redirect URLs 使用 backend-password-login.md 的四個正式路徑。確認 SMTP 與 Email 變更確認設定；Email 變更保留 secure email change，確認新舊信箱。不要以全域自動確認略過後臺申請或 Email 變更。
4. 部署新版 dist/。先升級 SQL，再部署前端；舊頁籤的題目寫入若未帶版本會被拒絕，請重新整理頁面。
5. 使用測試名冊驗收首次啟用、登出／密碼登入、重設密碼、部分公布、名冊鎖定、封存／還原、系統管理者分析封存紀錄及 Email 變更。永久刪除只用可拋棄測試梯次，由真人重新輸入系統管理者 Email、密碼與梯次名稱驗收。

本機 SQL 測試、建置成功與已推送程式都不等於正式服務已完成這些步驟。

## 權限、評分與資料一致性

nptc_private 資料表啟用 RLS，anon／authenticated 沒有直接資料表權限。public RPC 逐次檢查身分與權限；一般管理員可管理未封存課程、名冊、題目、成績與公布；系統管理者額外可管理帳號、封存、還原與永久刪除。初始系統管理者及自身帳號受到降權／停用保護。

- 五大面向滿分皆大於 0、合計 100；後端重新加總得分，不能信任前端送來的總分。分數與 Global Rating 成對填寫或留空；0 分有效。
- 每題以該梯次該題 Rating＝3 的平均分數為邊緣及格線；沒有可用資料時尚無法判定，沒有固定 60 分及格線。
- 題目逐題公布／撤回。公布後該題題目與成績鎖定；已有分項成績就不能變更配分。只要有任何題目公布，整份名冊即鎖定，避免刪除學員改變已公布門檻。
- 題目 stations_revision、學員 revision 與梯次鎖共同防止舊草稿覆寫及公布／寫入競爭。新增梯次以管理員＋requestId 記錄建立請求；網路重試回傳同一個梯次。
- 所有舊版題目寫入都轉至現行保護；舊整梯次公布及總分寫入拒絕使用。
- 封存保留歷史題目、背景與成績；個人背景資料僅更新未封存名冊，經 Auth 確認的 Email 變更為可稽核的身分同步例外。
- 日常課程清單不包含封存梯次；系統管理者的學習分析含封存歷史，一般管理員分析限未封存梯次，畫面會標明範圍。
- 封存與永久刪除需要兩分鐘內的密碼登入及一次性 session；永久刪除還需已封存與完整梯次名稱，由後端再次授權。

## 官方醫院清單

scripts/sync-hospitals.mjs 擷取官方公開名冊並保留 public/data/accredited-hospitals.json 快取。pnpm build:sql 依快取重建 SQL 種子；新版前端與後端都使用已安裝的 nptc_private.hospital_directory，避免兩套名單不同步。

更新快取或每日前端建置不會自動改正式資料庫名冊。要更新正式清單，重新產生 SQL，檢閱差異並執行完整現行升級。下載失敗保留快取，不能宣稱清單已刷新。後端拒絕不在清單的自由文字；既有歷史院名保留。正式資料庫的實際清單版本取決於最後一次 SQL 升級所使用的快取。

## 權限、評分與資料一致性

nptc_private 資料表啟用 RLS，anon／authenticated 沒有直接資料表權限。public RPC 逐次檢查身分與權限；一般管理員可管理未封存課程、名冊、題目、成績與公布；系統管理者額外可管理帳號、封存、還原與永久刪除。初始系統管理者及自身帳號受到降權／停用保護。

- 五大面向滿分皆大於 0、合計 100；後端重新加總得分，不能信任前端送來的總分。分數與 Global Rating 成對填寫或留空；0 分有效。
- 每題以該梯次該題 Rating＝3 的平均分數為邊緣及格線；沒有可用資料時尚無法判定，沒有固定 60 分及格線。
- 題目逐題公布／撤回。公布後該題題目與成績鎖定；已有分項成績就不能變更配分。只要有任何題目公布，整份名冊即鎖定，避免刪除學員改變已公布門檻。
- 題目 stations_revision、學員 revision 與梯次鎖共同防止舊草稿覆寫及公布／寫入競爭。新增梯次以管理員＋requestId 記錄建立請求；網路重試回傳同一個梯次。
- 所有舊版題目寫入都轉至現行保護；舊整梯次公布及總分寫入拒絕使用。
- 封存保留歷史題目、背景與成績；個人背景資料僅更新未封存名冊，經 Auth 確認的 Email 變更為可稽核的身分同步例外。
- 日常課程清單不包含封存梯次；系統管理者的學習分析含封存歷史，一般管理員分析限未封存梯次，畫面會標明範圍。
- 封存與永久刪除需要兩分鐘內的密碼登入及一次性 session；永久刪除還需已封存與完整梯次名稱，由後端再次授權。

function SurveyForm({ assignment, onCancel, onComplete }: { assignment: SurveyAssignment; onCancel: () => void; onComplete: (time: string) => void }) {
  const [answers, setAnswers] = useState<(number | null)[]>(() => assignment.definition.items.map(() => null));
  const [busy, setBusy] = useState(false), [error, setError] = useState('');
  // Failed requests keep the same id and answers, so a retry cannot create a second submission.
  const pending = useRef<{ id: string; answers: string } | null>(null);
  const [uncertain, setUncertain] = useState(false);
  async function submit() {
    setError('');
    try {
      validateSurveyAnswers(answers, assignment.definition.items.length);
      const serialized = JSON.stringify(answers);
      if (!pending.current) pending.current = { id: crypto.randomUUID(), answers: serialized };
      if (pending.current.answers !== serialized) throw new Error('正在確認上一筆提交，請先重試原作答。');
      setBusy(true);
      const result = await rpc<{ ok: true; submitted_at: string }>('nptc_survey_submit', { body: { assignmentId: assignment.id, version: assignment.scale_version, requestId: pending.current.id, answers } }, AbortSignal.timeout(15000));
      onComplete(result.submitted_at);
    } catch (cause) {
      if (pending.current) setUncertain(true);
      setError((cause as Error).name === 'AbortError' ? '連線逾時，尚無法確認是否已提交。請重試原作答或返回清單確認。' : (cause as Error).message);

  }

export function scoreSurvey(definition: SurveyDefinition, answers: unknown): SurveyScores {
  const min = definition.minScore ?? 1, max = definition.maxScore ?? 6;
  validateSurveyAnswers(answers, definition.items.length, min, max);
  const itemScores = answers.map((n, i) => definition.reverseItems?.includes(i + 1) ? min + max - n : n);
  const dimensions = Object.fromEntries(Object.entries(definition.dimensions ?? {}).map(([name, items]) => [name, items.reduce((total, i) => total + itemScores[i - 1], 0)]));

create or replace function nptc_private.survey_score(definition jsonb,answers jsonb) returns jsonb
language plpgsql immutable set search_path='' as $$
declare scores jsonb; total integer; flexibility integer; structure integer;
begin
 if jsonb_typeof(answers) is distinct from 'array' then raise exception '請提供完整的 14 題作答。'; end if;
 if jsonb_array_length(answers)<>jsonb_array_length(definition->'items') then raise exception '請完成每一題。'; end if;
 if exists(select 1 from jsonb_array_elements(answers) a where jsonb_typeof(a)<>'number' or a::text !~ '^[1-6]$') then raise exception '每題只能選擇 1 至 6 的整數。'; end if;
 select jsonb_agg(score order by i),sum(score),
  sum(score) filter(where (definition->'dimensions'->'flexibility') @> to_jsonb(i::integer)),
  sum(score) filter(where (definition->'dimensions'->'structure') @> to_jsonb(i::integer))
 into scores,total,flexibility,structure from (
  select i,case when (definition->'reverseItems') @> to_jsonb(i::integer) then 7-(a::text)::integer else (a::text)::integer end score
  from jsonb_array_elements(answers) with ordinality t(a,i)
 ) x;
 return jsonb_build_object('itemScores',scores,'total',total,'flexibility',flexibility,'structure',structure);
end;$$;

create or replace function public.nptc_survey_submit(body jsonb) returns jsonb
language plpgsql security definer set search_path='' as $$

end;$$;

create or replace function nptc_private.survey_score(definition jsonb,answers jsonb) returns jsonb
language plpgsql immutable set search_path='' as $$
declare scores jsonb; total integer; flexibility integer; structure integer;
begin
 if jsonb_typeof(answers) is distinct from 'array' then raise exception '請提供完整的 14 題作答。'; end if;
 if jsonb_array_length(answers)<>jsonb_array_length(definition->'items') then raise exception '請完成每一題。'; end if;
 if exists(select 1 from jsonb_array_elements(answers) a where jsonb_typeof(a)<>'number' or a::text !~ '^[1-6]$') then raise exception '每題只能選擇 1 至 6 的整數。'; end if;
 select jsonb_agg(score order by i),sum(score),
  sum(score) filter(where (definition->'dimensions'->'flexibility') @> to_jsonb(i::integer)),
  sum(score) filter(where (definition->'dimensions'->'structure') @> to_jsonb(i::integer))
 into scores,total,flexibility,structure from (
  select i,case when (definition->'reverseItems') @> to_jsonb(i::integer) then 7-(a::text)::integer else (a::text)::integer end score
  from jsonb_array_elements(answers) with ordinality t(a,i)
 ) x;
 return jsonb_build_object('itemScores',scores,'total',total,'flexibility',flexibility,'structure',structure);
end;$$;

create or replace function nptc_private.survey_score(definition jsonb,answers jsonb) returns jsonb
language plpgsql immutable set search_path='' as $$
declare points jsonb:='[]'::jsonb; dims jsonb:='{}'::jsonb; result jsonb; mn integer:=coalesce(definition->>'minScore','1')::integer; mx integer:=coalesce(definition->>'maxScore','6')::integer;
 n integer; i integer; point_value integer; total integer:=0; dimension text; indices jsonb; subtotal integer;
begin
 if jsonb_typeof(answers) is distinct from 'array' then raise exception '請提供完整作答。'; end if;
 n=jsonb_array_length(definition->'items');
 if jsonb_array_length(answers)<>n then raise exception '請完成每一題。'; end if;
 if exists(select 1 from jsonb_array_elements(answers) a where jsonb_typeof(a)<>'number' or a::text !~ '^(0|[1-9][0-9]*)$') then raise exception '每題必須選擇量尺中的整數。'; end if;
 for i in 0..n-1 loop
  point_value=(answers->>i)::integer;
  if point_value<mn or point_value>mx then raise exception '作答超出量尺範圍。'; end if;
  if coalesce(definition->'reverseItems','[]'::jsonb) @> to_jsonb(i+1) then point_value=mn+mx-point_value; end if;
  points=points||jsonb_build_array(point_value); total=total+point_value;
 end loop;
 for dimension,indices in select key,value from jsonb_each(coalesce(definition->'dimensions','{}'::jsonb)) loop
  select coalesce(sum((points->>((j::text)::integer-1))::integer),0)::integer into subtotal from jsonb_array_elements(indices) j;
  dims=dims||jsonb_build_object(dimension,subtotal);
 end loop;
 result=jsonb_build_object('itemScores',points,'total',total,'dimensions',dims);
 if dims ? 'flexibility' then result=result||jsonb_build_object('flexibility',dims->'flexibility'); end if;
 if dims ? 'structure' then result=result||jsonb_build_object('structure',dims->'structure'); end if;
 return result;
end;$$;

- 量尺兩端文字、反向題及構面名稱。

此版尚未提供自由文字、多選、跳題或逐題不同量尺。若其他量表有這些需求，需再依實際內容擴充。

加入梯次時會保存完整題目快照；日後新增其他版本時，也不會改變已發布問卷或既有作答。計分依問卷快照，由伺服器換算；前端不能指定總分。

DTI-SK 使用先前確認的 14 題，保留左右敘述及 1–6 量尺，第 1、5、6、7、10 題使用修訂文字。持續標示「繁體中文翻譯初稿，未經驗證」。其既定反向題及構面分類仍保存於該版本。

## 學員流程

教師分享的連結格式為 `/student/?survey=問卷發布編號`。學員未登入時先輸入帳密，登入後接續開啟該份問卷；已登入且符合梯次名冊時直接填答。

本機示範學員：`student-demo@example.test`／`demo1234`。本次將示範登入改為 Email 與密碼，讓試用方式與正式帳密登入相近；正式環境仍沿用既有 StudentLogin 及帳號啟用流程。

每題單選且不預選答案。繳交後只顯示已完成及收件時間，不回傳學員原答或分數。網路逾時時保留相同提交編號，可重試原作答，避免建立重複紀錄。

「我的 OSCE 成績」頁僅顯示「問卷填寫公告」，列出量表名稱、是否完成、發布與完成時間。題目不直接放在成績頁，未完成且開放中的問卷可由連結前往填寫。公告 API 不含問卷分數、教師備註、題目、反向規則或其他學員資料。原有 OSCE 成績功能不變。

## 本機資料與正式資料分開

`pnpm dev:demo` 使用瀏覽器 localStorage，僅供同一瀏覽器的本機試用。示範連結中的 localhost 網址不能直接讓其他人的裝置連到您的電腦；正式網站與中央資料庫安裝完成後，才可分享正式網址。

本機舊示範資料會保留。原前後測分類移成可編輯的教師備註，不再用來限制填答順序。這是資料格式調整，不代表舊紀錄被刪除或重新計分。
